# Site VERS - pacote completo
- Rodar: `python -m http.server 8000` nesta pasta e abrir http://localhost:8000 (não abrir o index.html direto).
- `assets/`            = os assets que o site usa (caminhos do código).
- `assets-originais/`  = TODOS os assets baixados por ID, com os caminhos originais (Logos, Uploads incl. 139 fotos Sesc Barretos e fontes, photos, clients, scraps).
- `fonts/`             = Elgraine e Nebulica (todas as variações).
- `PROMPT-COPILOT.md`  = instruções para o Copilot replicar o site.
Não existem no artefato: Brandbook PDF, Marca/*.svg, Icones/*, olho-invertido-white.png.
