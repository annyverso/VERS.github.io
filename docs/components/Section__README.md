The page is a stack of `Section`s. Alternate grounds: never two identical grounds in a row, never more than two brand colours across a page besides black and white.

```jsx
<Section ground="indigo" eyebrow="Os três verbos" title="Produzir. Distribuir. Materializar."
  lede="Cada verbo nomeia uma frente de trabalho, com seu próprio repertório de competências.">
  …
</Section>
```

`ground="indigo"` is the interface indigo of the `vers-indigo` theme (on screen only). Decks, print and other brand pieces use the palette indigo #4B59A7 (brandbook p. 50).
